# 📁 Premium Batch Converter Bot

A Telegram bot that converts files (.csv, .vcf, .txt etc) and extracts phone numbers with country detection.

## ✨ Features

- 📄 File conversion (CSV, VCF, TXT)
- 🔢 Number extraction & filtering
- 🌍 Country detection with premium flags
- 📊 Statistics & leaderboard
- 🎨 Premium Telegram emojis

## 🚀 Setup

1. Open `bot.py`
2. Replace `YOUR_BOT_TOKEN_HERE` with your bot token from [@BotFather](https://t.me/BotFather)
3. Run:
```bash
python bot.py
